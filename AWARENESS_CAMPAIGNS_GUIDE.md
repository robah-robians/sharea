# Awareness Campaigns - Complete Guide

## What Are Awareness Campaigns?

Awareness campaigns are **admin-created announcements and messages** that are broadcast to the Share Hope community. They are NOT fundraising campaigns—they don't collect donations or have funding goals. Instead, they serve to:

1. **Communicate important messages** to the platform community
2. **Broadcast alerts and updates** about platform activities
3. **Educate users** about causes and initiatives
4. **Promote emergency responses** to urgent situations
5. **Share seasonal or time-sensitive information**

---

## Key Characteristics

| Feature | Details |
|---------|---------|
| **Created by** | Admin only |
| **Purpose** | Broadcast messages, not raise funds |
| **Has donations** | ❌ No |
| **Has funding goal** | ❌ No |
| **Has deadline** | ⚠️ Optional (can be open-ended) |
| **Visibility** | Public (shown in announcements carousel on homepage) |
| **Target audience** | Configurable (donors, NGOs, or both) |
| **Priority levels** | Yes (Urgent, High, Medium, Low) |
| **Date range** | Optional start and end dates |

## How Awareness Campaigns Work

### 1. Admin Creates Campaign
Admin goes to: **Admin Dashboard → Awareness Campaigns → Launch New Campaign**

**Fields to fill:**
- **Title**: Campaign name (e.g., "Emergency Relief Fund Open", "New Partnership Announcement")
- **Description**: Full message content
- **Target Audience**: Who sees it (Donors / NGOs / Both)
- **Campaign Type**: 
  - General Awareness
  - Fundraising Drive
  - Educational
  - Emergency Alert
  - Seasonal Campaign
- **Priority Level**: Urgent / High / Medium / Low
- **Start Date**: When campaign becomes visible (optional)
- **End Date**: When campaign stops showing (optional)
- **Action Link**: Optional URL for "Learn More" button
- **Cover Image**: Optional visual (optional)
- **Activate**: Checkbox to make it live immediately

### 2. Campaign Goes Live
Once created and activated, the campaign appears in:
- **Homepage announcements carousel** (Latest Updates section)
- **All users can see it** (donors, NGOs, admins)

### 3. Users Interact
- Users see the announcement in the carousel
- Can read the full message
- Can click "Learn More" if action link is provided
- Can navigate through announcements with left/right arrows

### 4. Admin Manages
Admin can:
- **Edit** campaign details anytime
- **Activate/Deactivate** to show/hide it
- **Delete** campaign permanently

## Campaign Types Explained

### 1. General Awareness
**Purpose**: Share information about causes, initiatives, or platform updates
**Example**: "Learn about our new partnership with local NGOs"

### 2. Fundraising Drive
**Purpose**: Promote a specific fundraising initiative (but not a specific campaign)
**Example**: "Help us reach our Q1 fundraising goal of $100K"
**Note**: This is different from individual fundraising campaigns—it's a general call to action

### 3. Educational
**Purpose**: Teach users about topics related to charitable giving
**Example**: "How to verify NGO legitimacy before donating"

### 4. Emergency Alert
**Purpose**: Urgent announcements about crises or emergencies
**Example**: "Earthquake Relief: Donate now to support affected communities"
**Priority**: Usually set to "Urgent"

### 5. Seasonal Campaign
**Purpose**: Time-specific campaigns (holidays, awareness months, etc.)
**Example**: "World Water Day: Support clean water initiatives"

## Priority Levels

Priority affects **display order** in the carousel (higher priority shows first):

| Priority | Color | Use Case |
|----------|-------|----------|
| **Urgent** | Red (#ef4444) | Crisis, emergency, time-critical |
| **High** | Orange (#f59e0b) | Important announcements, major updates |
| **Medium** | Blue (#3b82f6) | Regular updates, general information |
| **Low** | Gray (#9ca3af) | Informational, non-urgent |

## Target Audience

### Donors
- Users who donate to campaigns
- See announcements about fundraising opportunities
- See emergency alerts

### NGOs
- Verified NGO organizations
- See announcements about platform updates
- See educational content

### Both
- All users see the announcement
- Most common choice for general updates

---

## Date Range (Optional)

### Start Date
- Campaign becomes visible on this date
- If not set: visible immediately upon activation
- Useful for scheduling announcements in advance

### End Date
- Campaign stops showing after this date
- If not set: campaign stays visible indefinitely
- Useful for time-limited campaigns (seasonal, emergency relief)

**Example Timeline:**
```
Jan 1 ─────────────────────────────────────── Dec 31
       ↑ Start Date                    ↑ End Date
       Campaign visible for 11 months
```

## Best Practices

### ✅ DO:
- Use **Urgent priority** only for true emergencies
- Set **end dates** for time-limited campaigns
- Include **action links** when you want users to take action
- Use **clear, concise titles** (max 60 characters)
- Target the **right audience** (don't spam NGOs with donor-only content)
- **Activate immediately** for urgent announcements
- Use **professional cover images** for visual impact

### ❌ DON'T:
- Create awareness campaigns for individual fundraising (use fundraising campaigns instead)
- Set everything to "Urgent" priority (dilutes urgency)
- Leave campaigns active indefinitely without end dates
- Use vague titles like "Important Update"
- Target "Both" when you only need one audience
- Create duplicate campaigns
- Forget to deactivate old campaigns

## Technical Details

### Database Table: `awareness_campaigns`
```sql
CREATE TABLE awareness_campaigns (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    description LONGTEXT NOT NULL,
    target_audience ENUM('donors', 'ngos', 'both') DEFAULT 'both',
    campaign_type ENUM('awareness', 'fundraising', 'education', 'emergency', 'seasonal'),
    priority ENUM('low', 'medium', 'high', 'urgent') DEFAULT 'medium',
    start_date DATE,
    end_date DATE,
    action_link VARCHAR(500),
    image_url VARCHAR(500),
    is_active BOOLEAN DEFAULT 1,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id)
);
```

## Troubleshooting

**Q: Campaign not showing on homepage?**
- A: Check if `is_active = 1`
- A: Check if start_date is today or earlier
- A: Check if end_date is today or later (or null)

**Q: Can I donate to an awareness campaign?**
- A: No, awareness campaigns don't accept donations. Use fundraising campaigns for that.

**Q: Can I assign an awareness campaign to an NGO?**
- A: No, awareness campaigns are broadcast to all users. Use target_audience to control visibility.

**Q: How many awareness campaigns can I create?**
- A: Unlimited, but only 1 shows in the carousel at a time (highest priority first).

**Q: Can I edit a campaign after it's live?**
- A: Yes, edit anytime. Changes take effect immediately.

**Q: What happens when end_date passes?**
- A: Campaign automatically stops showing (even if is_active = 1).
